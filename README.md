## Запуск

Требуется Node.js >= 18.

### Способ 1. Свой URL (основной)

node speedtest.js <URL> или npm start -- <URL>

### Способ 2. Локальный воспроизводимый пример (рекомендуется)

Не зависит от внешних сайтов, работает одинаково у всех.
Нужны два терминала.

Терминал A:
npm run gen:testfile
npx serve . --listen 3000

Терминал B:
node speedtest.js http://localhost:3000/test-10mb.bin

Ожидаемый вывод (цифры будут отличаться):

#1: 300 ms, 10.00 MiB
#2: 222 ms, 10.00 MiB
...
Download speed : 372.37 Mbps (46.55 MB/s)

⚠️ На loopback нет сети — цифра упирается в скорость диска и CPU, а не в интернет.
Локальный пример проверяет корректность скрипта, а не ваш канал.

### Способ 3. Внешние примеры (для демонстрации формата вывода)

npm run example:1   # 99px.ru, ~70 КБ
npm run example:2   # russiadiscovery.ru, ~245 КБ

Оба примера — маленькие файлы. Они показывают формат вывода, но НЕ дают
представления о скорости вашего канала: на таких объёмах время запроса
определяется задержкой (latency), а не пропускной способностью (throughput).
Цифры Mbps в этих примерах — «сколько успело пролезть за время запроса»,
а не реальная скорость интернета.

⚠️ Внешние примеры нестабильны по своей природе:
- Скорость зависит от вашего канала до конкретного сервера, его загрузки и CDN.
- Некоторые сайты ограничивают автоматические запросы (HTTP 429) или
  отдают маленькие файлы.
- Для точных замеров используйте собственный файл от нескольких МБ
  (способ 1) или локальный пример (способ 2).
